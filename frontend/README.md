# SatQuery AI - Frontend Architecture

The frontend interface for SatQuery AI will provide an interactive dashboard for remote sensing analysis.

### Target Capabilities
- **Single-image Explorer**: Upload optical remote sensing imagery, query with natural language, view model responses with grounding bounding boxes.
- **Bi-temporal Change Inspector**: Side-by-side or slider comparison of T1 and T2 images with change mask overlays.
- **Optical + SAR Multimodal Viewer**: Synchronized dual-channel viewer with radar intensity layer toggles.
- **Execution Trace & Explainability Inspector**: Real-time visualization of agent routing, model confidence, and tool invocation steps.
